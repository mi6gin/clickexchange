# ClickExchange

Кликер-биржа на Django: майни монеты кликами, прокачивай апгрейды. Биржа с живыми графиками — на следующих этапах.

## Запуск в Docker (прод-конфигурация)

```bash
cp .env.example .env            # заполнить секреты
./deploy/gen-dev-certs.sh       # самоподписанный TLS-сертификат для localhost
docker compose up --build -d
```

Открыть https://localhost (браузер предупредит о самоподписанном сертификате).

Стек: **Nginx** (TLS, редирект, статика) → **Gunicorn** → **Django** + **PostgreSQL 17** + **Redis**.

Секреты только через `.env` (`DJANGO_SECRET_KEY`, пароль БД). В production-настройках включены:
HSTS на год, `SECURE_SSL_REDIRECT`, secure-cookies, Redis-кэш для axes (корректный счёт брутфорса между воркерами).

## Локальная разработка

SQLite и DEBUG=True без Docker:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```

Открыть http://127.0.0.1:8000 , зарегистрироваться и играть.

## Механики (этапы 1–2)

**Кликер:**
- Клик = монета; шанс крита ×5 (базово 5%, качается апгрейдом)
- Энергия: тратится на клики, регенерится лениво по времени (1 ед / 2 сек)
- Автокликер — пассивный доход, начисляется при заходе в игру (оффлайн-доход капится 2 часами)
- Апгрейды (до 10 уровня, цена растёт геометрически): сила клика, шанс крита, автокликер, максимум энергии

**Биржа:**
- Активы с ценами по геометрическому броуновскому движению: тик каждые 5 сек
- Рынок «догоняет» время лениво — при каждом обращении к странице/API (Celery придёт на этапе 3)
- Покупка/продажа, средняя цена позиции, реализованный и нереализованный P&L
- Свечной график на голом canvas без библиотек, авто-обновление каждые 10 сек
- **Авто-IPO**: компании генерируются процедурно (тикер, название, архетип риска) с шансом при каждом заходе на биржу, лимит рынка — 12 активов; вручную: `python manage.py generate_assets N`

## Безопасность

- Пароли хэшируются **Argon2** (старые PBKDF2-хэши апгрейдятся при логине)
- **django-axes**: блокировка после 5 неудачных входов на 15 минут (по юзернейму и IP)
- CSRF-защита, httpOnly-сессии, валидаторы паролей — из коробки Django
- Docker-стек: TLS через Nginx, HSTS, секреты в env, непривилегированный пользователь в контейнере
